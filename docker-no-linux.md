# Docker no Linux

Docker é uma plataforma que permite executar aplicações em containers.

## Verificar versão

```bash
docker --version
```

## Listar containers

```bash
docker ps
```

## Listar imagens

```bash
docker images
```

## Executar container

```bash
docker run nginx
```

## Docker Compose

Executar ambiente definido em docker-compose.yml:

```bash
docker compose up -d
```
