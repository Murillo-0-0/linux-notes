# Gerenciamento de Processos

## Listar processos

```bash
ps aux
```

## Monitorar em tempo real

```bash
top
```

ou

```bash
htop
```

## Encerrar processos

```bash
kill PID
```

Forçar encerramento:

```bash
kill -9 PID
```

## Conceitos Aprendidos

* Processo
* PID
* Serviços
* Daemons
* Monitoramento do sistema
