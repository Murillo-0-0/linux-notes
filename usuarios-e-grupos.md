# Usuários e Grupos

## Ver usuário atual

```bash
whoami
```

## Listar usuários

```bash
cat /etc/passwd
```

## Criar usuário

```bash
sudo adduser usuario
```

## Adicionar usuário a grupo

```bash
sudo usermod -aG grupo usuario
```
